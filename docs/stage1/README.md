# docs/stage1

Stage 1 hardware: an Arduino Nano (328P) driving the chip through two MCP23S17 SPI expanders, with
switched VCC and GND, INA219 current sense and an SSD1306 OLED.

## Rules

- **Everything here is generated. Don't edit it by hand.** Connections live in `tools/design.py`.
  Change that, then rerun the generator in the table below and commit the data change and the regenerated
  outputs together.
- The schematic sheets, `WIRING.md` and (from stage 1a) the firmware pin map all come from
  `design.py`. If any two disagree, the generator or `design.py` is wrong, not the output.
- Sheets are named `sch-<n>-<block>.svg/.png`, one per block of the block diagram. Sheet 0 is the index.
  Net flags with the same label on two sheets are the same wire.
