# docs/stage1

Stage 1 hardware: an Arduino Nano (328P) driving the chip through two MCP23S17 SPI expanders, with
switched VCC and GND, INA219 current sense and an SSD1306 OLED. Everything here is generated from
`tools/design.py`; edit that, not these files.
